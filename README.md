# Calendar Widget

A minimalist desktop calendar widget with a soft pink aesthetic, elegant typography, and a translucent background.

Built with **HTML, CSS, JavaScript, and Electron**, this project explores desktop app development and UI styling.

## Features

- Displays the current month and year
- Starts the week on Monday
- Highlights the current day
- Frameless desktop window
- Compact, fixed-size widget

## Built With

- HTML5
- CSS3
- JavaScript
- [Electron](https://www.electronjs.org/)
  
## How to use

### 1. Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### 2. Clone this Repo

```
git clone (https://github.com/kiaracarvalho006-del/calendar-widget.git)
cd calendar-widget
```

### 2. Install Node.js

Make sure you have Node.js installed, then run:

```
npm install
```

This installs Electron and any other modules required to run the app.

### 3. Run the App Locally

```
npm run start
```

This will open your Calendar Widget as a desktop application powered by Electron.

## Project Structure

| File / Folder | Purpose |
| --- | --- |
| `index.html` | Defines the calendar's HTML structure |
| `styles.css` | Contains the calendar's visual styling |
| `script.js` | Frontend JavaScript controlling calendar logic |

| `package.json` | Project metadata & dependencies |

| `package-lock.json` | Auto-generated lock file for dependencies |

## Design

The interface was designed around a soft pink palette, rounded corners, translucent surfaces, and elegant serif typography.

The goal is to create a simple calendar widget that complements a personalized desktop setup.
